Markdownは、文章の構造をプレーンテキストで表すための記法です。このページでは基本構文を、ソースと描画結果の順に紹介します。

## 見出しと段落

ページのタイトルとは別に、本文は `##` から始めると階層が整理しやすくなります。段落の間には空行を入れます。

```markdown
## 大きな見出し
### 小さな見出し

最初の段落です。

次の段落です。
```

### 小さな見出しの例

最初の段落です。日々の気づきから、長い技術解説まで、同じ書き方で整理できます。

次の段落です。空行を挟むことで、文章のまとまりを表現できます。

## 強調とインラインコード

```markdown

```

**重要な言葉**、*少し強調したい言葉*、そして `npm run build`。

アスタリスクを文字として見せたいときは、`\*` のようにエスケープします。たとえば \*この部分は強調しません\*。

## コードブロック

バッククォート3つでコードを囲み、最初の行に言語名を付けます。コード内の記号はMarkdownとして解釈されません。

````markdown
```typescript
const article = { title: 'Hello, InkRail', published: false };
console.log(article.title);
```
````

```typescript
const article = { title: 'Hello, InkRail', published: false };
console.log(article.title);
```

コードの右上にはコピー・折り返しの操作があります。長い行でも、本文全体を横にはみ出さずに読めます。

## 区切り線
