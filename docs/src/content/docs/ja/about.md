title: このプロジェクトについて

Laravel React Secure Starter Kit は、Laravel + React でアプリを作るためのスターターキットです。**アカウントの変更通知、ログイン中の端末の確認、セキュリティに関する操作の記録**を備えています。

利用者が「知らない変更やログインに気づくこと」と、運用担当者が「何が起きたかを調べて対処すること」を助けます。

## 何ができる？

| こんなときに | 使える機能 |
| --- | --- |
| パスワードやメールアドレスが変更された | メールで変更を知らせます |
| 見覚えのない端末でログインされている | ログイン中のセッションを確認し、終了できます |
| アカウントで何が起きたか調べたい | 重要な変更や認証の失敗を記録し、許可された運用担当者が確認できます |
| お知らせを届けたい・障害を把握したい | アプリ内通知やメール通知、運用アラートを使えます |

たとえば、使わなくなったブラウザーのログインを終了したり、パスワード変更の通知を受け取ったりできます。利用者自身の操作に加えて、運用担当者が特定ユーザーのセッションを終了する機能もあります。

## どこから生まれたのか

このプロジェクトは、多言語対応の [react-starter-kit-i18n](https://github.com/catatsumuri/react-starter-kit-i18n) の `main` を基盤にしています。

Laravel + React の構成と英語・日本語の翻訳基盤を引き継ぎ、セキュリティに関する追加機能を、ひとまとまりで使える別のスターターキットとして分離しました。

ログイン、パスワードリセット、二要素認証、パスキーなどの認証機能は、派生元にもあります。この版では、その周りに**変更を知らせる機能、セッションを管理する機能、操作を記録する機能**を追加しています。

## 使い始める前に

まず押さえておきたい点は、次の3つです。具体的な設定手順は導入の章で説明します。

- **PHP 8.4 以上が必要です。** 派生元の PHP 要件から変更しています。
- **セッションの失効には `SESSION_DRIVER=database` が必要です。** ほかのドライバーでもアプリは利用できますが、このキットの失効機能は使えません。
- **メール通知には配信設定が必要です。** 初期設定ではメールの内容をログへ出力します。

初めて使う方は、[導入](../getting-started/)から進めてください。追加機能を知りたい方は、関心のある項目から読めます。
